# SMTH visual identity

The primary mark is an original eclipse / black-hole motif. It contains no planet and no copied Nothing OS glyph pattern.

The two and only two dot/accent combinations are:
- Signal coral: `#FF315A`
- Ion teal: `#20D9C2`

Core surfaces remain black, white, and graphite. Accent colours are reserved for the mark, active states, and status signals. The wordmark in user-facing branding is simply **SMTH**.
